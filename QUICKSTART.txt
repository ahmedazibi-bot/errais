 🚀 1. INSTALLATION (First Time Only)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Clone the repository
    git clone https://github.com/ahmedazibi-bot/errais.git
    cd errais

Step 2: Run automated setup
    python setup.py

    This will automatically:
    ✓ Check Python version (3.9+ required)
    ✓ Create virtual environment
    ✓ Install all dependencies
    ✓ Configure environment
    ✓ Create project directories
    ✓ Generate library files

Step 3: Configure API key (optional but recommended)
    Edit .env file and add your OpenAI API key:
    LLM_API_KEY=sk-your-key-here

 ▶️  2. RUNNING THE APPLICATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

OPTION A: Using startup script (recommended)
    
    Windows:
        run.bat
    
    Mac/Linux:
        ./run.sh

OPTION B: Manual activation
    
    Windows:
        venv\Scripts\activate
        python app.py
    
    Mac/Linux:
        source venv/bin/activate
        python app.py

OPTION C: Run example workflow
    
    source venv/bin/activate  # Activate first
    python run_design.py       # Runs automatic example

 📱 3. MENU GUIDE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

When you run app.py, you'll see this menu:

    1. ➕ Create New Project
       └─ Create a new irrigation project
       └─ Select crop, water source, hydraulic system
       └─ Specify area and location

    2. 📂 Load Land Boundary (GeoJSON)
       └─ Import land boundaries from GeoJSON file
       └─ Supports standard GeoJSON format

    3. 🎯 Generate Irrigation Design
       └─ Generate sprinkler layout
       └─ Specify sprinkler spacing and discharge
       └─ Calculate hydraulic network

    4. 📊 Generate Reports (Word + Excel)
       └─ Create professional Word report
       └─ Create detailed Excel spreadsheet
       └─ Includes BOQ (Bill of Quantities)

    5. 📍 View Sprinkler Coordinates
       └─ View generated sprinkler positions
       └─ See X,Y coordinates

    6. 💧 Assess Water Quality
       └─ Check water source suitability
       └─ View pH, EC, SAR values

    7. 📚 Browse Crop Library
       └─ View available crops
       └─ See Kc values, root depth, growing period

    8. 💧 Browse Water Quality Library
       └─ View water sources
       └─ Check suitability ratings

    9. 🔧 Browse Hydraulic Constraints
       └─ View irrigation system types
       └─ Check pressure ranges, velocity limits

    10. ⚙️  View Configuration
        └─ See current system settings
        └─ View API configuration

    11. ❌ Exit
        └─ Close application

    2. Select: Option 1 (Create New Project)
    3. Fill in:
       - Project name: "Farm A"
       - Client name: "Ahmed"
       - Location: "Cairo"
       - Area: "50" hectares

       - Select water: "Well"
       - Select system: "Standard Sprinkler"

    5. Enter:
       - Spacing: "6.0" meters
       - Discharge: "2500" L/min

WORKFLOW B: View Library Data

    2. Select Option 7 (Browse Crops)

    4. Select Option 8 (Browse Water Quality)

WORKFLOW C: Run Automated Example
    1. Activate: source venv/bin/activate
    2. Run: python run_design.py
    3. Watch automatic workflow complete
    4. See generated reports in ./reports/

WORKFLOW D: Assess Water Quality
    1. Run: python app.py
    2. Select Option 1 (Create Project) - Create a test project
    3. Select Option 6 (Assess Water Quality)
    4. View detailed water analysis
    5. Check suitability for irrigation

 ⚙️  5. CONFIGURATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Edit .env file to customize:

DATABASE SETTINGS:
    MONGODB_URI=mongodb://localhost:27017
    DATABASE_NAME=errais

API CONFIGURATION:
    LLM_API_KEY=sk-your-key
    LLM_MODEL=gpt-4-turbo
    LLM_TEMPERATURE=0.7

APPLICATION SETTINGS:
    DEBUG=True
    LOG_LEVEL=INFO
    REPORTS_FOLDER=./reports
    DATA_FOLDER=./data

DEFAULT VALUES:
    DEFAULT_SPRINKLER_SPACING=6.0
    DEFAULT_PIPE_DIAMETER=50
    MAX_SPRINKLER_VELOCITY=2.0
    MIN_SPRINKLER_PRESSURE=200

PATHS:
    LIBRARIES_PATH=./libraries
    CONFIG_PATH=./config

 🔧 6. TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PROBLEM: "ModuleNotFoundError: No module named 'shapely'"
SOLUTION:
    1. Activate virtual environment
    2. Run: pip install -r requirements.txt
    3. Try again

PROBLEM: "Command not found: python app.py"
SOLUTION (Mac/Linux):
    1. Run: source venv/bin/activate
    2. Then: python app.py

SOLUTION (Windows):
    1. Run: venv\Scripts\activate
    2. Then: python app.py

PROBLEM: "Permission denied: ./run.sh"
SOLUTION:
    chmod +x run.sh
    ./run.sh

PROBLEM: Library files not found
SOLUTION:
    Run setup.py again to regenerate library files

PROBLEM: MongoDB connection error
SOLUTION:
    Ensure MongoDB is running:
    - Windows: mongod.exe
    - Mac: brew services start mongodb-community
    - Linux: sudo systemctl start mongodb
    Or update MONGODB_URI in .env

PROBLEM: OpenAI API error
SOLUTION:
    1. Check API key in .env file
    2. Verify key is valid at https://platform.openai.com
    3. Check account has credits
    4. Verify internet connection
